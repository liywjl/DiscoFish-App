# DiscoFish

Public bug reports and feature requests for the DiscoFish desktop and mobile apps.

- [Report a bug](https://github.com/liywjl/william-discofish-app/issues/new?template=bug_report.yml)
- [Suggest a feature](https://github.com/liywjl/william-discofish-app/issues/new?template=feature_request.yml)
- [Browse existing issues](https://github.com/liywjl/william-discofish-app/issues)
- [Download DiscoFish](https://discofishapp.com)

This repository currently contains the issue tracker and reporting guidance. App source may be published here later; it is not included yet.

Issues and attachments are public. Review diagnostic reports before attaching them, and remove passwords, license keys, pairing codes, personal information, and private URLs. The apps do not upload reports automatically.

For security vulnerabilities or exposed credentials, use [private vulnerability reporting](https://github.com/liywjl/william-discofish-app/security/advisories/new), not a public issue.
